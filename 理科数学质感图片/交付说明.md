# 理科数学质感图片 · 交付说明

## 结果
- **精选50张**：`精选50张/`，横版 JPEG（3840×2176 / 2752×1536），适合 PPT 底图
  - 数学类：公式黑板、粉笔板书、几何图形、函数图像、计算器/绘图工具、数学笔记（约22张）
  - 理科类：化学实验室/试管/分子结构、物理/量子光效、显微镜、科研场景、星空/星云/望远镜/行星、DNA（约28张）
- **备选11张**：`备选/`，质量合格未入编
- **描述档案**：`理科数学照片-description/`（50个md）+ `理科数学照片-description-备选/`（11个md）
  - 每图一档：基本参数表（格式/分辨率/宽高比/像素/大小/DPI/主色调前5色值）+ 视觉描述六段（一句话/主体细节/色调光照/构图视角/质感风格/建议用途）
  - 各含 `_参数总表.md` 索引（分辨率、大小、主色、一句话描述）
- 剔除目录：`rejected/`（6张）+ `rejected2/`（19张）+ `rejected3/`（6张），共31张偏题留档可查

## 视觉核对（三轮，比工科批更严）
1. 80张拼网格 → glm-4v-flash 逐格查 → 剔6张（人物肖像×3、风光、彩蛋、美甲）
2. 逐张生成视觉描述（兼第三只眼）→ 暴露第一轮大量漏检（美甲、护肤品、食材、保龄球、健身房、潜水艇、考古等19张）→ 全部剔除
3. 从备选提拔18张合格图 + 补抓12张数学类新图（逐张描述核对后 1 入精选、4 入备选、7 剔除）
- 最终精选50张：**0 偏题、0 坏图、0 水印**，图片↔描述一一对应、六段完整性全部通过

## 经验
理科/数学关键词在图库的噪声远高于工科（"formula"命中美甲/护肤品、"blackboard"命中健身房/路面粉笔画）。
**逐张视觉描述核对是必需的兜底环节**，网格缩略图核对只能拦住明显跑题项。

## 流水线脚本（同目录，与工科批同款）
build_manifest.py → download.py → make_sheets.py → vision_check.py → describe.py → finalize.py
apikey.txt 需放同目录（GLM_API_KEY）；describe.py 兼做逐张视觉核对。
